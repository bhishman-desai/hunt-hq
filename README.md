# Hunt HQ

## Introduction

This repository is a six-agent kit for direct outreach: remote jobs, freelance gigs, and small-business projects. An orchestrator reads `plan.md` first, then loads the charter, preferences, and role files. The files in `profile/` are dummy. Jordan Demo is not a real person. Replace those files before a real hunt.

## Getting Started

1. Read [plan.md](plan.md).
2. Follow the setup order in that file.
